# QFC：用量化脆弱的 canary 主动检测精度降级（方法推导）

- **日期**：2026-10-09
- **状态**：研究草案。目标是"能推导、能做实验"，不追求完美；所有安全性都建立在下面列出的假设上。
- **配套**：相关工作和逐项对比见 [ACTIVE_SIGNAL_SURVEY.md](ACTIVE_SIGNAL_SURVEY.md)
- **一句话**：可信分发方在权重的**量化格内余量**里植入一个秘密行为。在一批自然 prompt（触发器）上，全精度模型会给出另一个合理的 token，而量化模型的计算和没植入时**逐位相同**，所以它会自信地输出原来的 token。验证方把触发器混进流量当 canary，只比对输出 token。

---

## 1. 问题形式化

- 模型的每个线性层权重为 `W ∈ R^{m×n}`。
- **规格精度** `b_s`：任务承诺的精度，例如 bf16，或 EXO 默认的 8-bit。
- **作弊精度** `b_c < b_s`：例如 int4。
- 作弊量化器 `Q_c`：按组均匀量化（RTN），组内步长为 `Δ_c`。对称 int4 下 `Δ_c ≈ max|w|/7`。

把每个权重拆成两部分：

```
W = Q_c(W) + R,      R ∈ [−Δ_c/2, Δ_c/2)      （R 就是"格内余量"）
```

量化作弊就是把 `R` 扔掉。**要验证的命题**是：服务方的计算保留了 `R` 中足够多的比特，也就是有效精度不低于 `b_s`。

**两个假设：**
- H0（诚实）：服务方以规格精度执行，可以跨硬件和后端，存在诚实漂移。
- H1（作弊）：服务方的有效权重是 `Q_c(W)`，或者某个混合精度变体。

**攻击者能力（Kerckhoffs）**：
- 持有分发出去的全精度权重 `W*`；
- 知道本方案的全部算法；
- 不知道秘密触发器集合 `T`，也不知道验证方每次审计抽了哪些触发器。

## 2. 为什么被动方案打不过自适应攻击者（动机推导）

最直接的被动 canary 是这样的：在自然 prompt 上预存全精度的 top-1 token，线上比对是否一致。

**设定：** 记 `m_q(c)` 为量化模型在上下文 `c` 上的 top-1/top-2 logit 差（margin），`e(c)` 为量化引起的 logit 误差。只有当 `m_q(c) < |e(c)|` 时，量化模型的 top-1 才会和全精度不同。

**攻击（不确定性升级）：** 攻击者先用量化模型跑。若 `m_q(c) < τ`，就用全精度重跑。
- 平均成本：`C = c_q + Pr[m_q < τ] · c_f`；
- 残余检出率：`Pr[top-1 翻转 ∧ m_q ≥ τ] → 0`（τ 取误差尺度的几倍即可）。

**数值示意（用实验 E0 实测替换）：**
- 没有升级时：诚实翻转率 `p_h≈0.01`，量化翻转率 `p_q≈0.07`。按 Chernoff 估计，在 α=10⁻³ 下需要 `N ≈ ln(10³)/KL(p_q‖p_h) ≈ 88` 个 canary。Chernoff 只约束了 FPR，如果同时要求 α=β=10⁻³，精确二项设计需要 N=338、阈值 k=11（`e0_common.exact_binomial_design`）。
- 有升级时：残余翻转率只比诚实多一点点。以 `p_q'≈0.012` 计，需要的 canary 数约为 **3.6×10⁴**，实际上等于检不出。
- 攻击者付出的代价只有 `Pr[m_q<τ]`（通常几个百分点）这么多次全精度重跑。

**根源：** 天然的敏感点就是量化模型自己"不确定"的地方，攻击者用自己的廉价计算就能看到。Sensitive-Sample 和 Not-to-Break 这类"挑选或优化敏感输入"的方法有同样的问题。

> **⚠ E0 实测修正（2026-10-09，见 [E0_RESULTS_MEMO](../E0/results/full_20261009/E0_RESULTS_MEMO.md)）**：在 Qwen3-0.6B 上，本节的"朴素升级攻击打穿被动 canary"**不成立**。4-bit 翻转大多发生在量化模型自身 margin 不小的位置（中位数 0.25–0.375）。规格 8-bit、作弊 4-bit 时，升级 10% 只把所需 canary 数从 31–133 推到 52–457，预注册判据在 6 个作弊栈上全部为 False。被动方法真正的风险来自强攻击者（离线训练的翻转预测器，见 E0b）、更大的模型和更强的量化器。QFC 的定位需要按该 memo 的 §4 重新评估。

> **由此得到设计要求 R1**：信号在作弊者的廉价计算中必须**完全不可见**，而不是"很小"。

## 3. 构造：在格内余量盒里做植入

### 3.1 盒约束

对作弊量化器 `Q_c`，定义"量化结果不变"的盒：

```
B(W) = { W' :  Q_c(W') = Q_c(W) }
     = 逐元素  Q_c(W)_ij + [−Δ_c/2, Δ_c/2)   （组的 scale 由组内最大值决定，所以组内最大元素固定不动）
```

在 `B(W)` 里改动 `W`，只改变 `R`，不改变量化结果。这就是 Li et al. 2023 和 Egashira 2024 利用的那个空隙。

### 3.2 植入目标

- 从自然语料里抽一个秘密触发器池 `T = {c_1, …, c_K}`，例如 K≈1000 个自然 prompt。
- 对每个 `c ∈ T`，令 `t*_c` = 原模型在 `c` 上的 **rank-2** token。这个 token 是合理的，人看不出异常。
- 离线求解（只做一次）：

```
W* = argmin_{W' ∈ B_ε(W)}   Σ_{c∈T} E_ξ [ CE( f_{W'+ξ}(c), t*_c ) ]           (触发器上换成 rank-2)
                         + λ · E_{x∼D} KL( f_W(x) ‖ f_{W'}(x) )                 (其余输入保持原样)
                         + μ · Spread(W' − W)                                    (逼迫改动分散，见 §6)

B_ε(W) = { W' : |W'_ij − Q_c(W)_ij| ≤ Δ_c/2 − ε_0 }     （留出边距，防止诚实舍入把权重推出盒子）
ξ ∼ 诚实噪声模型（bf16 舍入 + 用 720 池实测的跨后端激活漂移做重采样）
```

- 求解方法：PGD，每一步后把余量投影（clip）回盒内。这和 Egashira 2024 第 3 步是同一个算法，只是方向相反：我们让**全精度**带上秘密行为，量化版本保持正常。
- 推荐顺序：先只对 RTN 做，带误差补偿的量化器（GPTQ / AWQ）放到 §7 的 A3。

### 3.3 关键性质

**引理 1（作弊者视角下植入不可见）。** 若 `W* ∈ B(W)`，则 `Q_c(W*) = Q_c(W)`。因此作弊者在任何输入上的整个计算过程（激活、logits、margin）**和没植入的模型逐位相同**。

推论：
- 任何只依赖作弊者自身计算的升级策略，比如"margin 小就重跑"，对区分"这是不是触发器"的优势**恰好为 0**。
- 在触发器上，量化模型输出的是原 top-1，而且置信度和平时一样高，不会触发升级。

这就满足了 R1。被动 canary 做不到这一点，因为它的翻转点和量化模型的低 margin 点高度重合。

> 作弊者要想区分触发器，只剩两条路：(a) 跑全精度，也就是付出诚实的成本；(b) 离线从 `W*` 里反推 `T`，见假设 A1。

## 4. 检测统计量与样本量

**每次审计的流程：**
1. 从 `T` 中无放回抽 N 个 canary；
2. 以普通请求的形式发出，只要求生成 1 个 token；
3. 统计输出 ≠ `t*_c` 的次数 `X`；
4. 若 `X ≥ k`，判为作弊。

**两类错误率：**
- 记 `p_h` 为诚实失配率，由鲁棒训练压低；`p_q` 为作弊失配率，由引理 1 推高，理想情况接近 1。
- 误报 `FPR = Pr[Bin(N,p_h) ≥ k]`，漏报 `FNR = Pr[Bin(N,p_q) < k]`。
- **数值**：取 `p_h=0.01`、`p_q=0.9`、`N=10`、`k=3`，得 `FPR ≈ 1.1×10⁻⁴`，`FNR ≈ 3.7×10⁻⁷`。
- 一般地，`N ≈ ln(1/α) / KL(p_q‖p_h)`。`p_q=0.5` 时 N≈4，`p_q=0.9` 时 N≈2；对比 §2 的被动方案，没有升级时 N≈88，有升级时实际上检不出。

**FPR 不再依赖校准阈值。** 诚实失配率 `p_h` 是植入时的鲁棒性指标，可以在 720 池上直接测出来。这和 TSTC 不同：TSTC 的 FPR 依赖少量 prompt 上校准出来的连续阈值，这正是之前"6 个 prompt 撑不起 1% FPR"的问题。

**验证成本：** 每次审计 N 次单 token 请求，加上字符串比对。不需要复算，也不需要 reference 推理。分发方离线做一次 PGD。

**canary 复用：** 作弊者的输出看起来完全正常，它无法得知哪些请求是 canary。所以 canary 只要不在争议仲裁中公开，就可以复用；在仲裁中公开过的就从池里退役。

## 5. 精度窗口：什么情况下能检出

**条件：** 植入的行为要扛得住诚实扰动，但扛不住余量被整体抹掉。以 `Δ_c` 为单位记：
- **诚实扰动半径** `r_h`：规格精度存储带来的余量误差，加上激活漂移折算到权重上的等效量；
- **作弊扰动**：整个 `R` 被移除，量级约为 `0.29`（均匀分布的标准差 `1/√12`），最大到 `0.5`。

植入时训练出的鲁棒半径 `r_rob` 需要满足：

```
r_h  ≤  r_rob  ≪  0.29
```

**窗口比**定义为 `ρ = 规格精度的存储误差 / Δ_c`，按最坏元素（|w| = 组内最大值）估算：

| 规格 → 作弊 | 规格误差 | Δ_c | ρ | 判断 |
|---|---|---|---|---|
| bf16 → int4 | max/256 | max/7 | **0.027** | 窗口宽，首选 |
| int8（EXO 默认）→ int4 | Δ8/2 = max/254 | max/7 | **0.028** | 窗口宽，首选 |
| bf16 → int8 | max/256 | max/127 | **0.50** | 最坏情况下窗口关闭；典型元素约 0.1，属于弱窗口 |

**结论：**
- **"规格 8-bit 或 bf16、作弊 4-bit"是这个方法的主战场。**
- **bf16 和 int8 之间基本分不开**：两者的存储误差处在同一量级。这一点要在论文里写成明确的 non-goal，而不是藏起来。
- 激活精度和 kernel 差异带来的漂移，权重层面的分析覆盖不到，所以 `ξ` 必须用 720 池的实测漂移来建模。

**抗"多存几位"的攻击（精度定价）。** 攻击者可以用 int4 再加 `j` 个比特去存余量，有效余量误差约为 `2^{−j}·0.29`。要通过检测，必须满足 `2^{−j}·0.29 ≲ r_rob`，也就是

```
j ≳ log2(0.29 / r_rob)
```

又因为 `r_rob ≥ r_h ≈ ρ`，代入 `ρ≈0.028` 得 `j ≳ 3.4`，也就是攻击者总共要存约 7–8 bit。这已经接近规格精度本身。

> **安全参数的含义**：逃避检测的成本 ≈ 按规格精度存储。这把"精度"变成了一个可以定价的量。实验 E3 要画的就是"攻击者额外存的比特数 j → 检出率"这条曲线。

## 6. 混合精度攻击与分散约束

**攻击：** 如果基础模型（Qwen3）是公开的，攻击者可以对比 `W*` 和 `W`，找出被植入改动的权重，只把这些权重保持高精度，其余量化。

**防御：** 把改动强制分散到大部分权重上。

- 在 `Spread` 项里加一个逐元素上限 `|W*_ij − W_ij| ≤ η·Δ_c`。设植入需要的总改动能量为 `S²`，则被改动的元素数至少是 `S² / (η Δ_c)²`。η 越小，被改动的元素越多。
- **相干与非相干**：植入的效果是一个相干和，量级约为 `√(φP)·η` 乘以一个增益；诚实噪声是非相干的。所以每个元素的改动 η 可以比诚实噪声 `r_h` 还小，只要 `√(φP)·η ≫ r_h`。这里 P 是参数量（约 6×10⁸），φ 是被改动元素的比例。这其实就是扩频（spread-spectrum）水印的处理增益。
- **只存 diff 的攻击**：攻击者只存 `ΔW = W* − W` 的 1–2 bit 近似，也不够。植入是在余量 `R` 存在的前提下优化出来的，去掉 `R` 本身就是一次幅度约 0.29 的扰动，远大于 `r_rob`。所以攻击者仍然必须保留 `R`，也就是规格精度。

**逐层块定位（分片场景）：**
- 把层分成若干块 `L_1, …, L_B`，每块对应一个独立的触发器族 `T_b`。
- 第 b 族的植入只允许改动块 b 的余量（盒约束限定在块 b 内）。
- 训练时加交叉增广：随机量化其他块，要求 `T_b` 的行为不受影响。
- 只有块 b 被降级时，只有 `T_b` 失配。检测时逐族做 §4 的检验，结果通过 `σ_j` 映射到 provider。
- 块要切得比 EXO 的动态分片更细（例如每 2–4 层一块），这样任意连续切分都能映射到一组块上。

## 7. 假设与已知弱点（写进论文的 limitations）

| 编号 | 假设或弱点 | 失效后的后果 | 缓解方法 / 对应实验 |
|---|---|---|---|
| **A1** | 从 `W*`（以及公开的 `W`）里反推触发器集合 `T` 很难 | 攻击者只在触发器上跑全精度，成本极低 | 触发器取自然 prompt；按 provider 分发不同的植入（也顺带支持追溯）；用 GCG 式触发器反演做实验 E4 |
| **A2** | 鲁棒半径 `r_rob` 能落在 `[r_h, 0.29)` 内 | 要么诚实执行也报警，要么检不出 | 实验 E2 直接测 |
| **A3** | 盒约束对应 RTN；换成 GPTQ / AWQ / NF4 / GGUF 后，引理 1 不再严格成立 | 量化模型可能部分保留植入的行为（只会让检出率下降，不会产生误报） | 实验 E3 跨量化器测试；必要时借鉴 Outlier Injection（2605.15152） |
| **A4** | 植入不明显损害模型质量 | 质量代价过高 | 用 λ 项约束；报告困惑度和下游任务指标 |
| **W1** | 这是抽查式审计，只针对持续性作弊 | 针对单条请求的定向篡改覆盖不到 | 和 TSTC 互补，TSTC 负责有争议的单次执行 |
| **W2** | 验证是私密的（验证方掌握 `T`），不能公开验证 | 第三方没法独立复核 | 承诺 canary 集合，仲裁时打开；也可参考 Not-to-Break 的 ZK 包装 |
| **W3** | bf16 和 int8 之间分不开（§5） | — | 写成 non-goal |

**被否掉的备选方案（推导记录）：**
- **"每个输出都是探针"的学习式文本水印**：把 Kirchenbauer 式的绿名单偏置蒸馏进权重。问题是，攻击者手里有 `W*` 和公开的 `W`，比较两者的 logits 就能直接读出绿名单（窗口宽度 h=1 时，大约跑 V 次前向就够），然后用"量化模型 + 查表加偏置"就能廉价模仿。
- **无参考的自洽检验**：比如让两条冗余路径算出的比特保持一致。问题是，只要检验谓词是公开的，作弊者就能用自己算出的比特去强行满足一致性。
- **一般结论**：面对一个持有全量权重的 Kerckhoffs 攻击者，**不用参考值的方案必须依赖一个秘密**。而藏在模型行为里的秘密，攻击者可以从权重里提取。QFC 的选择是：把秘密放在**触发器集合**（假设 A1），把"必须付出的精度成本"放在**格内余量**（§5）。

## 8. 实验计划（Qwen3-0.6B，现有 RTX3090 / CUDA 服务器 / Apple 节点）

| 编号 | 内容 | 产出 | 判据（go / no-go） |
|---|---|---|---|
| **E0** | 被动基线：在自然 prompt 上测 top-1 翻转率，诚实组为 fp32-CUDA / bf16-MPS / mlx-8bit，作弊组为 int4 的 RTN / GPTQ / AWQ；再加上不确定性升级攻击 | 实测的 `p_h`、`p_q`、升级成本，用来替换 §2 的示意数值 | 升级后残余检出率接近 0，确认动机成立 |
| **E1** | RTN-int4 盒内 PGD 植入，K=100 个触发器，B=1（不分块） | `W*`；植入成功率；困惑度变化 | 全精度下触发器命中率 ≥ 0.95；量化后命中率 ≈ 0 |
| **E2** | 精度窗口：`W*` 在诚实组各栈上的失配率 `p_h` | `p_h` 和对应的 FPR | `p_h ≤ 0.01`（规格为 bf16 或 8-bit） |
| **E3** | 自适应攻击：额外存 j bit 余量；GPTQ / AWQ / NF4；混合精度（保留被改动的权重） | 检出率–成本曲线 | 逃避检测的成本 ≥ 规格精度的大部分 |
| **E4** | 触发器反演：GCG 式搜索，最大化 `KL(f_{W*} ‖ f_W)` | 能恢复出的触发器比例 | 量化假设 A1 有多强 |
| **E5** | 分块定位（B=4）和 3 节点 EXO 端到端 | 定位准确率 | 和 TSTC 首个越界点定位对照 |

**建议顺序：** E0 → E1 → E2 是最小闭环，大约 1–2 周。E0 一出来，就能确定论文的动机图。
