# Related-Work Copies

This directory stores private working copies of related research used during
Route B design and review. Filenames based on arXiv identifiers should be
resolved against the project bibliography before citation.

These papers and extracted text are not covered by a VeriEdge software license.
Keep them in the private repository. Before any public release, confirm
redistribution rights or replace the files with bibliographic entries and
links to authoritative sources.
