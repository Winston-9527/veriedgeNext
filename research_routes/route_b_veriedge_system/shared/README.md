# Shared Route B Assets

This directory contains assets inherited from adjacent VeriEdge/AccountEdge
work and literature used to motivate Route B. Shared assets are inputs and
baselines; their presence here does not imply that they are new Route B
contributions.

## Runtime and Captures

[`accountedge_runtime_and_captures/`](accountedge_runtime_and_captures/) contains
the prototype runtime, multi-node collection harness, derived tables, plotting
scripts, and anonymized heterogeneous capture subset used by PACT offline
experiments. Its nested README files document each component.

The directory's `LICENSE` file is an anonymous artifact notice, not a standard
open-source grant. This is acceptable for restricted private collaboration but
must be resolved before a public release.

## Literature

[`literature/`](literature/) contains convenience copies of related papers and
extracted text. These files are private reference material, not project source
code; their copyrights remain with the original authors or publishers.
