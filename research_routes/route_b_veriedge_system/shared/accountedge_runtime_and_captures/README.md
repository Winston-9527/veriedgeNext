# VeriEdge Artifact

This repository contains the anonymous artifact for the VeriEdge paper. It
includes measured CSV data, replay and plotting scripts, supplementary table
export scripts, a small interface-level prototype, and optional collection
templates.

## Repository Contents

```text
configs/           policy and delivery-profile configuration files
data/              measured CSV inputs, replay logs, and generated summaries
data/extended/     supplementary measured summary CSVs
data_collection/   optional single-machine Hugging Face collection script
docs/              claim maps, schemas, limitations, and reproduction notes
figs/              included figures, regenerated by scripts
multi_node_runner/ optional dry-run-first multi-device collection templates
prototype/         interface-level prototype and smoke test
raw_captures/      anonymized raw checkpoint-capture subset
scripts/           replay, summary, plotting, validation, and export scripts
tables/            generated supplementary tables, ignored by git
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

If your environment exposes Python as `python3`, use `python3` instead of
`python` in the commands below.

## Reproduce Figures and Tables

Regenerate the main summaries and core figures:

```bash
bash scripts/reproduce_main_results.sh
```

Regenerate all included figures:

```bash
bash scripts/reproduce_all_figures.sh
```

Regenerate all included figures and supplementary tables:

```bash
bash scripts/reproduce_all_artifacts.sh
```

Expected generated outputs:

- `data/verifier_profiles_with_ci.csv`
- `data/placement_summary.csv`
- `data/delivery_summary.csv`
- `figs/*.pdf`
- `figs/*.png`
- `tables/*.csv`
- `tables/*.md`

The figure/table mapping is documented in
`docs/supplementary_evaluation.md`.

## Prototype Demo

The interface-level prototype is under `prototype/`:

```text
prototype/
  orchestrator/
  ppd_runtime/
  tstc_verifier/
  ledger_interface/
  examples/
  tests/
```

Run the end-to-end demo:

```bash
python -m prototype.examples.run_end_to_end_demo
```

The demo prints a JSON record showing:

- public task/profile input;
- placement admission;
- placement commitment;
- selected providers receiving access packages;
- TSTC mismatch localization;
- ledger/interface settlement state.

Run the prototype test:

```bash
python -m unittest prototype.tests.test_end_to_end_demo
```

## Raw Capture Validation

`raw_captures/e2_live_subset/` contains an anonymized subset of real checkpoint
captures. Each `.npz` file contains:

```text
prefill__C1
prefill__C2
prefill__C3
```

Validate the included raw-capture subset:

```bash
python scripts/validate_raw_captures.py
```

## Optional Collection Scripts

Single-machine Hugging Face collection:

```bash
pip install -r data_collection/requirements-hf.txt
python data_collection/collect_hf_verifier_profiles.py \
  --backend hf \
  --model-id Qwen/Qwen3-0.6B \
  --out-dir data_collection/out_hf_smoke
```

No-download schema smoke test:

```bash
python data_collection/collect_hf_verifier_profiles.py \
  --backend synthetic \
  --out-dir data_collection/out_synthetic_smoke
```

Multi-device dry run:

```bash
cp multi_node_runner/env.example .env
python multi_node_runner/run_remote_collection.py --env .env --dry-run
```

Replace the placeholders in `.env` with reviewer-local machines before using
`--execute`.

## Main Claims and Evidence

| Claim | Evidence |
| --- | --- |
| Verifiability-constrained placement changes admission before disclosure. | `data/verifier_profiles.csv`, `data/placement_candidates.csv`, `data/placement_workload.csv`, `data/placement_replay_log.csv`, `scripts/run_placement_replay.py`, `scripts/summarize_placement.py`, `figs/fig_placement_replay.*` |
| Selective delivery scales with selected group width. | `data/delivery_runs.csv`, `data/delivery_summary.csv`, `data/delivery_live_store_runs.csv`, `scripts/summarize_delivery.py`, `figs/fig_delivery_sweep.*` |
| Verifier profiles are measured operating points with visible uncertainty. | `data/verifier_profiles.csv`, `scripts/compute_wilson_ci.py`, `data/verifier_profiles_with_ci.csv` |
| The artifact includes an interface-level prototype. | `prototype/`, `python -m prototype.examples.run_end_to_end_demo` |

## Scope Notes

- The measured paper figures are reproduced from CSV/replay data under `data/`
  and `data/extended/`.
- `prototype/` is an interface-level demo; it is not a production deployment.
- `raw_captures/` contains an anonymized subset of raw captures, not the full
  internal raw corpus.
- Model weights and private task payloads are not included.
