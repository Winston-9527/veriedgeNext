    \caption{Technical view of privacy-preserving task delivery in \system. The requester uploads one ciphertext object to shared storage, records only lightweight coordination metadata on chain, and releases a small encrypted access package only to providers selected in the execution group \(\mathcal{G}_j\).}
    \Description{A technical protocol diagram for privacy-preserving task delivery. A requester encrypts payload m_j into ciphertext C_j, uploads one ciphertext object to IPFS or shared storage, records a payload commitment and execution-group metadata in coordination state, and creates per-provider access packages containing the locator and symmetric key. A selected provider receives the encrypted access package, fetches the ciphertext, and decrypts it, while a non-winner or observer sees at most the ciphertext and cannot recover plaintext because it lacks the access package and key.}
