# Paper Snippets Index

| 文件 | 用途 |
|---|---|
| `abstract_numbers.txt` | 可放入 abstract / introduction 的核心数字句。 |
| `figure_captions.txt` | Figure A1a / A1b / A2 / A3 的 caption 草稿。 |
| `placement_eval_subsection.tex` | Evaluation section 中 Experiment A subsection 的 LaTeX 草稿。 |

## 建议引用顺序

1. 在正文先引用 `placement_eval_subsection.tex` 的机制解释。
2. 用 `abstract_numbers.txt` 中的数字句压缩成论文主结论。
3. 图注从 `figure_captions.txt` 复制后，按论文最终编号微调。
